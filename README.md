# 📈 Curva Desplazable con Streamlit

Aplicación interactiva que muestra dos curvas cúbicas:
- 🔵 **Curva azul fija:** $f(x) = x^3 + 4$
- 🔴 **Curva roja punteada móvil:** $g(x) = x^3$, desplazable con sliders

## 🚀 Despliegue local

```bash
git clone <tu-repositorio>
cd curva-desplazable
pip install -r requirements.txt
streamlit run app.py
